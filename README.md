# Orpheus

Music platform for the Daemoniorum ecosystem.

## Structure

- `orpheus/` - Core music library
- `orpheus-audio/` - Audio processing
- `orpheus-desktop/` - Desktop application (Rust/Tauri)
- `orpheus-music-platform/` - Web platform
- `orpheus-standalone/` - Standalone tools

See `CLAUDE.md` for development instructions.
